📊 Sales Data Analyzer | Excel Data Analytics Project
An Excel-based data analytics project that explores sales performance, customer purchasing patterns, regional contribution, product categories, and monthly sales trends. The workbook combines data analysis techniques with visual storytelling through KPIs, pivot tables, and charts.
📌 Project Overview
The Sales Data Analyzer project uses a dataset of 200 sales records to turn raw sales data into meaningful business insights. It demonstrates how Excel can be used to organize data, perform statistical analysis, compare performance, and present findings in a dashboard.

The analysis focuses on:
- Overall sales and profit performance
- Regional and product-category comparisons
- High-value customer identification
- Monthly sales trends and growth
- The relationship between sales and profit
🎯 Project Objectives
1. Highlight the top 10 customers based on total purchases using Conditional Formatting.
2. Explore how changing discounts affects total profit using What-If Analysis.
3. Perform Linear Regression to study the relationship between Profit and Sales.
4. Generate Descriptive Statistics using the Data Analysis ToolPak.
5. Display monthly sales growth with percentage values and directional arrows.
6. Create a timestamp column using the NOW() function.
7. Identify high-value customers using INDEX(), MATCH(), and filters.
8. Analyze total sales by region and product category using Pivot Tables.
9. Create bar, line, and pie charts to visualize key performance indicators.
10. Present important findings through an interactive-style dashboard.
